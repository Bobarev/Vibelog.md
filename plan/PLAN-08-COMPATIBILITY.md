# PLAN-08: Совместимость с Backlog.md

## Задача

Проверить, что Vibelog.md совместим с Backlog.md по формату данных, CLI и MCP.

## Важное ограничение

**Оригинал Backlog.md НЕ запускается** на macOS 10.15 Catalina (Bun с нативными бинарниками). Поэтому проверка совместимости — **статическая**:

1. Сравнение форматов файлов (frontmatter, тело, имя файла).
2. Сравнение CLI-команд и флагов по исходникам и `CLI-INSTRUCTIONS.md`.
3. Сравнение MCP-инструментов по исходникам.
4. Round-trip тесты на реальных файлах.

## Источники для сверки

- `../Backlog.md/backlog/tasks/*.md` — реальные задачи
- `../Backlog.md/backlog.config.yml` — конфиг
- `../Backlog.md/CLI-INSTRUCTIONS.md` — CLI
- `../Backlog.md/ADVANCED-CONFIG.md` — конфиг
- `../Backlog.md/src/` — исходники
- `https://github.com/MrLesk/Backlog.md` — README, документация

## Тесты совместимости

### 1. Формат файла задачи

- Взять 3-5 реальных задач из `Backlog.md/backlog/tasks/`.
- Парсить Vibelog.md → все поля должны распарситься.
- Сериализовать обратно → результат должен совпасть с оригиналом (по крайней мере по frontmatter).
- Создать новую задачу Vibelog.md → сравнить формат с оригиналом.

### 2. CLI

- Сравнить список команд и флагов: `CLI-INSTRUCTIONS.md` vs реализация.
- Сравнить формат вывода `task list`, `task view` (можно по коду/скриншотам из README).

### 3. MCP

- Сравнить названия инструментов и схемы параметров с `src/mcp/` оригинала.
- Проверить подключение MCP-сервера Vibelog.md к **Qwen Code**:
  - Документация Qwen Code по MCP.
  - Добавить сервер, проверить `tools/list`, вызвать `backlog_list_tasks`.

### 4. Конфиг

- Прочитать `Backlog.md/backlog.config.yml` через Vibelog.md.
- Убедиться, что все ключи распарсились.
- Записать конфиг Vibelog.md → сравнить структуру.

## Acceptance Criteria

- [ ] Vibelog.md читает реальные задачи Backlog.md
- [ ] Round-trip по frontmatter сохраняется
- [ ] CLI-команды и флаги совпадают
- [ ] MCP-инструменты совпадают
- [ ] Конфиг читается обоими
- [ ] MCP-сервер подключается к Qwen Code

## Definition of Done

- [ ] Все расхождения задокументированы в плане
