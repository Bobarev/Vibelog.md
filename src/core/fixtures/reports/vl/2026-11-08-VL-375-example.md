## Что произошло

`git_commit` отказывает на путях с кириллицей: сравнение `git diff --cached --name-only`
с переданными путями не совпадает из-за octal-экранирования.

## Воспроизведение

1. Создать файл `backlog/lessons/lesson-1-Кириллица.md`.
2. Вызвать `git_commit { paths: ["backlog/lessons/lesson-1-Кириллица.md"] }`.

## Ожидаемое

Коммит проходит; имя файла в git не экранируется.
