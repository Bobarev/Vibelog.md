## Description
<!-- SECTION:DESCRIPTION:BEGIN -->
Улучшение промптов фаз Vibelog (workflow spec/plan/code).

Проект создаётся в первую очередь для других проектов, поэтому промпты должны быть переносимыми и не ссылаться на внутренние задачи этого репозитория.

1. Фаза spec должна добавлять референсы (references) в задачу, если они упомянуты пользователем.
2. Проверить тексты всех промптов на упоминания внутренних задач VL-N — их не должно быть (для внешних проектов такие ID ничего не значат).
3. Фаза spec сейчас не читает задачи; если пользователь явно ссылается на какую-то задачу — разрешить её чтение для понимания контекста.
4. Если по итогу фазы spec предлагается добавить label — вывести это предложение в чат бота после «Готово».
5. Если пользователь начинает текст с тега (например #agent) или нескольких тегов — это labels: добавить их в задачу, убрав из заголовка и начала текста.
