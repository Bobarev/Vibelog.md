## Реализация: Co-authored-by vibelog-agent в коммитах (настройка `commit_coauthor`, дефолт — включено)

### Решение (архитектура)

Трейлер добавляется в ДВУХ местах, потому что коммиты делает и framework, и агент:

1. **Framework-коммиты** (`src/agent/task-commit.ts`, `src/agent/run-progress.ts`) — трейлер дописывается кодом, детерминированно.
2. **Коммиты агента по шаблонам** (`templates/phases/phase-code.md`, `phase-do.md`, `phase-close.md`, `phase-close-worktree.md`) — через новую подстановку `{{commitTrailer}}` (пустая строка, если настройка выключена), по образцу существующих подстановок VL-137/VL-154/VL-184.

Единый источник правды — новый core-модуль `src/core/commit-trailer.ts` (без зависимостей от bot/web, чтобы его могли импортировать и agent, и phase-prompt).

### Файлы и конкретные места

**1. НОВЫЙ `src/core/commit-trailer.ts`** (шапка-комментарий на русском, «почему»):
- `export const COMMIT_TRAILER = 'Co-authored-by: vibelog-agent <vb@xw2.ru>'`
- `export function resolveCommitCoauthor(cwd: string): boolean` — `loadSettings(cwd).commit_coauthor !== false` (дефолт **true**; мусор/отсутствие ключа → true; читается через `loadSettings` из `src/core/settings.ts`, ошибок не бросает).
- `export function appendCommitTrailer(message: string, enabled: boolean): string` — чистая: `message.trimEnd()`; если `!enabled` или сообщение уже содержит `COMMIT_TRAILER` → вернуть как есть (идемпотентность, повторный amend не дублирует); иначе `${msg}\n\n${COMMIT_TRAILER}`.
- `export function commitMessageArgs(cwd: string, message: string): string[]` — `['-m', appendCommitTrailer(message, resolveCommitCoauthor(cwd))]` (готовые аргументы для `execFileSync git`).
- `export function commitTrailerText(cwd: string): string` — `COMMIT_TRAILER` либо `''` (для подстановки в промпт).

**2. `src/agent/task-commit.ts`** (строки ~119–133, ветки amend/новый коммит):
- импорт `appendCommitTrailer`, `resolveCommitCoauthor` из `../core/commit-trailer.js`;
- ветка `--amend` (стр. 129): вместо `['commit','--amend','--no-edit','--no-verify']` — прочитать полное сообщение `git log -1 --pretty=%B`, собрать `appendCommitTrailer(fullMessage, resolveCommitCoauthor(cwd))` и вызвать `['commit','--amend','--no-verify','-m', newMessage]` (тема сохраняется, трейлер дописывается; `--no-edit` больше не годится — он не даёт изменить сообщение);
- ветка нового коммита (стр. 132): `['commit','--no-verify', ...commitMessageArgs(cwd, `docs(task): ${taskId} — token_usage (${phase})`)]`.

**3. `src/agent/run-progress.ts`** (стр. 160–170, `commitProgressChanges`): сообщение WIP-коммита собирать через `commitMessageArgs(cwd, `wip(${taskId}): прогресс фазы code до обрыва (${reason})`)` — трейлер и в WIP-коммитах.

**4. `src/web/phase-prompt.ts`** (`taskExtraVars`, блок возврата ~стр. 213–240): новая подстановка `commitTrailer: commitTrailerText(cwd)` (импорт из `../core/commit-trailer.js`). Порядок ключей — рядом с `taskModifiedFiles`/`taskReferences`.

**5. Шаблоны фаз** — в каждый шаг с `git commit -m "..."` добавить правило: «Если `{{commitTrailer}}` не пусто — передай его вторым `-m` (git делает из него отдельный абзац после пустой строки)»:

### Риски

- **R1 (amend переписывает сообщение)**: `--amend --no-edit` заменяется на `--amend -m <полное сообщение из %B>` — нужно брать `%B` целиком (не `%s`), иначе потеряется тело коммита. Тест на сохранение тела обязателен.
- **R2 (дубли трейлера)**: агент по шаблону и framework могут добавить трейлер дважды (amend поверх коммита агента) — `appendCommitTrailer` идемпотентен по `includes(COMMIT_TRAILER)`.
- **R3 (хрупкие тесты)**: `phase-prompt.test.mjs` жёстко проверяет `Object.keys(vars).length === 14` — обновить до 15 в том же коммите, иначе красный прогон.
- **R4 (типы веба)**: `SettingsData`/union патча в `web/src/components/settings/api.ts` — без правки `pnpm web:build` упадёт на `commit_coauthor`.
- **R5 (дефолт «включено»)**: `resolveCommitCoauthor` должен возвращать true при отсутствии файла/ключа/битом JSON — иначе настройка молча выключится (паттерн lesson-117: битая настройка не отключает рабочий дефолт).
- **R6 (пустой `-m`)**: при выключенной настройке `{{commitTrailer}}` подставляется пустой строкой — шаблон обязан требовать второй `-m` ТОЛЬКО при непустом значении, иначе git создаст пустой абзац.
