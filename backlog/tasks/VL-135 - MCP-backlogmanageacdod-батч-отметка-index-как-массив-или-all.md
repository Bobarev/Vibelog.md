## Description
<!-- SECTION:DESCRIPTION:BEGIN -->
После фикса VL-120 (валидация индекса) модель продолжает слать manage_ac/manage_dod массив-строку "[1, 2, 3]" — она хочет отметить НЕСКОЛЬКО пунктов за один вызов (сессия VL-121 code, 2026-10-12: пары падающих вызовов ac+dod подряд; ошибки теперь понятные, но вызов всё равно падает и тратит ход на повтор). Отсутствующая функция, а не ошибка валидации.

Решение: батч-отметка — index принимает: целое число (как сейчас), строку-число, МАССИВ индексов [1,2,3] (отметить/снять все перечисленные), строку «all» (все пункты списка). Результат: «Отмечено пунктов: 3 (1, 2, 3)». Валидация: каждый элемент массива — целое >=1 и <= длины; иначе ошибка со списком доступных (сохранить подсказку VL-120). Учить батчу и add (списки создаются добавлением — batch-add уже работает через массив строк, симметрия).
