- **npm publish и push необратимы** — разрешены для релизной задачи (AGENTS.md, решение Pavel 2026-10-04). Перезаписать 1.9.0 нельзя — при сбое после publish выпускать 1.9.1.

- **Пуш master после Close** (шаг 13, lesson-5) — автоматически его не делает никто; критичен, вынести в отчёт.
- **npm view сразу после publish** покажет старую версию (lesson-4) — не считать это ошибкой publish, повторить через 1–2 минуты.
- **Дата в CHANGELOG** — указать день реального выполнения Фазы 3.
- **Извлечение задач для вехи** — только regex на заголовки `- **VL-N:` (шаг 4); все `VL-\d+` захватывают контекстные упоминания (опыт VL-127).
