## Контекст

Обсуждение с Pavel (сессия по трём фичам веб-чата; это фича 1 из 3). Подробности решения — doc-24, инструкция по установке элемента — ref-23.

Сейчас чат не показывает вообще никакой обратной связи по расходу: `LlmUsage` возвращается из `streamChat` (`src/agent/llm.ts:92-100`), но в SSE-поток (`src/web/chat.ts`, события thread/text/tool_start/tool_end/approval/done/error/truncated) не попадает — клиент токенов не видит. Стоимость при этом уже умеет считаться: `calculateCost()` + `pricing` внутри `models.available[id]` (`src/core/analytics.ts`, `src/core/models.ts`).

Итог: пользователь не видит, во сколько обходится диалог и близко ли он к лимиту контекстного окна.

## Цель

Панель вверху веб-чата со текущим расходом: токены по типам (входящие / исходящие / кэш), потраченные рубли и процент занятого контекста. Статично приклеена сверху, полупрозрачная, с небольшими иконками.

## Решения

- Плейсмент: панель вверху чата (static/sticky), полупрозрачная (`bg-background/70` + `backdrop-blur-sm` + нижняя граница). Изначально рассматривался ring у кнопки Send (как в примерах assistant-ui) — отклонён.
- Компонент берём из assistant-ui Elements (ContextDisplay, вариант Bar/Text), установка ручная через shadcn-CLI (нужен прокси/VPN): `pnpm dlx shadcn@latest add "@assistant-ui/context-display"`. Элемент ставится исходником в проект, НЕ как npm-пакет — `@assistant-ui/react@0.15.31` его не экспортирует.
- Runtime-режим элемента (`useThreadTokenUsage` из `@assistant-ui/ai-sdk`) недоступен: чат на `useLocalRuntime` + свой ChatModelAdapter → standalone-вариант с пропом `usage` + `resetKey=threadId`.
- Процент контекста = ПИК (input + cache) по запросам треда, а НЕ сумма по ходам (usage каждого запроса уже включает весь промпт; иначе ринг упрётся в 100% на 2–3-м ходу).
- Рубли считаются по тарифу ТОЙ модели, что использовалась в треде (`pricingForModelId`), а не `models.default` — иначе после смены модели в пикере старые ходы посчитаются по чужому тарифу.
- Панель показывается только для непустого треда.
- Мобильная раскладка: `ModelPicker` показываем на узком экране (усечённый label), `PersonaPicker`/`PersonaBadge` прячем.
- В поповер элемента добавляем строку «Стоимость, ₽» (в оригинале только Input / Cached input / Output / Reasoning); reasoning не подмешиваем в output (как в VL-198).
