## Проблема

TUI агента (`src/agent/tui.ts`, VL-155) каждую секунду делал `out.write('\x1b[2J\x1b[H')` + полную перерисовку кадра: мигание, потерянный скролл, «прыгающий» курсор; стрим токенов затирался следующим тиком, а в альтернативном буфере пропадала возможность листать историю.

## Решение

Разделяй два вида вывода и не смешивай их:

1. **Append-транскрипт** — всё, что должно остаться в истории (реплики, стрим токенов, карточки tool calls, ошибки): только допись в поток, никогда не очистка экрана. Первый токен хода закрывает/снимает статусную строку, чтобы не писать поверх неё.
2. **Статусная строка** (счётчики: ход / токены / время) — единственное, что перерисовывается: `\r\x1b[2K` + текст, один ряд внизу. Тик по таймеру обновляет **только её**.
3. **Тик пропускается, пока открыта частичная строка стрима** — иначе `\r\x1b[2K` затрёт недописанный текст модели.

Интерактив (спиннер, `log`, `intro`/`outro`, промпты) отдаёшь `@clack/prompts`/`@clack/core`: библиотека сама считает ширину/переносы и перерисовывает собственную строку, а не кадр. Своё — только append-слой и статусная строка (VL-321).

## Пример

VL-321: `createRedraw` с `\x1b[2J\x1b[H` удалён целиком, вместо него `createAppender({ out, useColor })` с `appendStream`/`endLine`/`appendBlock`/`drawStatus`/`clearStatus`; шапка — один `p.intro`, карточки — `p.log.message(formatToolCard(...))` по завершении вызова, тик `setInterval(1000)` вызывает только `status.message(counters)` и не трогает экран.
