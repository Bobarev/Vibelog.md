## Проблема

При сокращении/переписывании README по стандарту Standard Readme легко потерять контент (427 → 150 строк): удаляемые разделы содержат уникальные детали, которых ещё нет в doc-*.

## Решение

1. Строгий порядок: **сначала** досдать переносимое в doc-6/doc-7 (проверить маркеры через document_search), **потом** перезаписывать README.
2. При удалении раздела README проверяй обратные ссылки в doc-* на него (circular-ссылки вида «подробнее: README, раздел X») — удаляй их в том же шаге.
3. После перезаписи — grep по маркерам перенесённого контента в README (0 совпадений) и node-скрипт проверки локальных ссылок.

## Пример

VL-193: README 427→78 строк; перенос в doc-6/7 шёл до перезаписи, circular-ссылка doc-6 «подробнее: README, раздел Workflow» удалена при переносе.
