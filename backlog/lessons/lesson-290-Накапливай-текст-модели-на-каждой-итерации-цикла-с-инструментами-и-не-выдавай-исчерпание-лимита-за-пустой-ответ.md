## Проблема
Цикл субагента-консультанта (`src/web/chat-subagent.ts`) присваивал `answer` только в ветке `toolCalls.length === 0`. Модель, вернувшая текст ВМЕСТЕ с tool_calls, теряла этот текст, а исчерпание жёсткого `CONSULTANT_MAX_ITERATIONS = 3` давало пустой `answer` → пользователь стабильно видел «Консультант не дал ответа — отвечай сам», хотя модель работала нормально и просто не успела дойти до финального текста.

## Решение
В любом цикле «модель + инструменты» накапливай последний непустой текст на КАЖДОЙ итерации (`lastText`), а не только в финальной ветке без вызовов; после цикла используй его как fallback. Исчерпание лимита итераций — не «пустой ответ»: возвращай частичный результат с перечнем вызванных инструментов и номером лимита, отдельно от исхода «модель вернула пустоту без вызовов». Лимит итераций делай настройкой, а не константой.

## Пример
Плохо: `if (resp.toolCalls.length === 0) { answer = resp.text.trim(); break; }` — три итерации с вызовами → `answer` пуст → «Консультант не дал ответа». Хорошо: `if (resp.text?.trim()) lastText = resp.text.trim();` на каждой итерации, после цикла `answer ||= lastText`, а при исчерпании лимита вернуть `{ok:false, partial:true, usedTools:[...]}` вместо пустой ошибки.
