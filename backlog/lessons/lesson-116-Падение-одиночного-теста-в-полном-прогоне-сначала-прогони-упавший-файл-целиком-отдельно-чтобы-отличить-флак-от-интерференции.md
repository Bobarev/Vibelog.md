## Проблема

В фазе Close (VL-264) полный прогон дал 1 падение: `src/web/orchestrator.test.mjs > E2E: оркестраторный спавн пишет meta.json сессии` — `SyntaxError: Unexpected end of JSON input` при чтении `meta.json` (файл частично записан). Легко принять за регрессию merge, хотя merge вообще не касался оркестратора.

## Решение

Порядок диагностики (дешевле, чем сравнение с родительским коммитом):
1. Прогнать **упавший тест по имени** (`-t "…"`): прошёл — подозрение на флак/параллельность.
2. Прогнать **весь упавший файл** отдельно: прошёл — это интерференция при полном прогоне (общие ресурсы, тайминги E2E-спавна), а не поломка кода.
3. Проверить, не идёт ли параллельный `vitest` в другом worktree (`ps aux | grep vitest`).
4. Только затем — максимум один повторный полный прогон, с причиной в отчётном комментарии. Повтор зелёный — фиксируй как флак и укажи имя теста в отчёте.

## Пример

```bash
npx vitest run src/web/orchestrator.test.mjs -t "E2E: оркестраторный спавн пишет meta.json"   # passed
npx vitest run src/web/orchestrator.test.mjs                                                  # 79/79 passed
ps aux | grep vitest | grep -v grep                                                           # пусто
npx vitest run   # полный прогон — 1860 passed, флак не повторился
```
