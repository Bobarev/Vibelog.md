## Проблема

Замена UI-библиотеки (например, Ink → собственный рендер) обычно тянет переписывание всей логики отображения вместе с декорациями.

## Решение

Выноси чистые функции форматирования в отдельный модуль, не зависящий от фреймворка (только данные → строки). Тогда при смене рендера меняются только «декорации» (компоненты → функции-строки/прямые write), а логика форматирования и её тесты остаются нетронутыми.

## Пример

VL-155: `src/agent/tui-format.ts` (чистые функции, 18 тестов) переиспользован без единой правки; `tui.tsx` (486 строк React/Ink) заменён на `tui.ts` (471 строка чистого Node.js: ANSI-константы, redraw(), прямой стриминг в stderr), публичный API `renderTui`/`renderInteractiveTui` и колбэки loop не менялись.
