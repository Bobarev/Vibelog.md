## Проблема

Бот запускает `vibelog browser --no-open` и вытаскивает URL регуляркой `/Веб-интерфейс Vibelog\.md:\s*(\S+)/` из stdout. Добавление новых строк вывода (LAN-адреса) легко ломает этот контракт или подсовывает боту ложный URL.

## Решение

Расширяй stdout только добавлением строк ПОСЛЕ первой, а первую строку с URL оставляй в неизменном формате; новые строки делай с отличающимся префиксом («Доступ из локальной сети: …»), чтобы регулярка бота их не ловила. Формирование строк вынеси в чистую функцию (`startupLines`) и закрепи тестом на точное содержимое первой строки.

## Пример

VL-266: `startupLines(host, port, addresses)` — первая строка всегда `Веб-интерфейс Vibelog.md: <local>`, далее LAN-строки; тест проверяет первую строку строго.
