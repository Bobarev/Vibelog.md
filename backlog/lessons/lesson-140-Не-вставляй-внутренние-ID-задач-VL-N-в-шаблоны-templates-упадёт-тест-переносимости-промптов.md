## Проблема

Правя `templates/phases/*.md` (промпты фаз, которые уходят во ВНЕШНИЕ проекты), легко
дописать в пояснение ссылку на свою задачу — «(VL-248)». Промпт переносится в чужие
репозитории, где этот ID ничего не значит, поэтому `src/web/phase-prompt.test.mjs`
(блок VL-157) проверяет все файлы `templates/` и `templates/phases/` регуляркой
`/\bVL-\d|\bVL-XX/i`. Падение: `phase-close-worktree.md: не должно быть внутренних ID задач VL-*`.

## Решение

В шаблонах промптов объясняй правило словами, без внутренних ID: «Ставить терминальный
статус при неотмеченных пунктах DoD можно только с непустым `dodOverride`» вместо
«Невыполненный пункт DoD (VL-248): …». Номер задачи — в комментариях кода (`src/`),
в README, doc-* и CHANGELOG; в `templates/` — никогда.

## Пример

Было (падает):

    - Невыполненный пункт DoD (VL-248): ставить терминальный статус …

Стало:

    - Невыполненный пункт DoD: ставить терминальный статус …
