## Проблема
В Plan-фазе VL-196 в план Code попало «обновить doc-6 (руководство, 87 КБ)». В Фазе 3 это оказалось дважды невозможным: (1) правила Фазы 3 прямо запрещают обновлять CHANGELOG и документы backlog/docs — их пишет Фаза Close после слияния; (2) даже без запрета полный контент doc не получить: MCP document_view отдаёт весь файл, но вывод инструментов обрезается на 8 КБ, а document_update принимает только полную замену контекста — 87 КБ не восстановить из контекста.

## Решение
План Фазы 2 не должен включать в Фазу 3 правку больших документов backlog/docs: либо переноси в Фазу Close явной строкой плана, либо фиксируй в плане ограничение («текст раздела готовится в notes задачи, применяет Close»). Если раздел всё же нужен — дай его готовый черновик в Implementation Notes задачи через MCP, чтобы Close вставил его в doc без поиска по задаче.

## Пример
VL-196: черновик раздела «Transient In Progress» оставлен в notes задачи, doc-6 обновит Close (AC4 остаётся незакрытой до Close).
