## Проблема

Тесты `src/web/phase-prompt.test.mjs` матчат конкретные подстроки шаблонов промптов (якоря вида «только целевой код», «Сразу после записи Implementation Plan») — правка текста шаблона ломает тесты незаметно.

## Решение

Перед правкой `templates/qwen-commands/*.md` выполняй `grep -n "якорная-подстрока" src/web/phase-prompt.test.mjs` для затронутых формулировок и сохраняй эти подстроки в новом тексте (или обновляй тест одновременно с шаблоном).

## Пример

VL-157: при удалении «(VL-134)» из phase-2.md сохранена якорная подстрока «не завершай фазу раньше» — тесты не упали.
