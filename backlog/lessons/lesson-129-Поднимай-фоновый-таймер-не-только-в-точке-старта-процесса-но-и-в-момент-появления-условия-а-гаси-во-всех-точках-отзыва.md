## Проблема

VL-272: `startSupervisorTimer` вызывался ровно в одном месте — при старте веб-сервера (`src/web/server.ts`), и первым делом требовал уже лежащего на диске grant'а (`if (findActiveGrant(cwd) === null) return false`). В продовом сценарии doc-19 §15 порядок обратный: сервер уже работает → пользователь согласует состав → выдаётся grant → идёт первая волна. Условие появляется ПОСЛЕ старта, таймер никто не перезаводит, а `runSupervisorTick` вызывался только из его `setInterval` — прогон после первой волны вставал: следующие волны не планировались, упавшие фазы не лечились, авто-баги не создавались. Юнит-тесты этого не ловили, потому что вызывали `runSupervisorTick` напрямую, минуя отсутствующую точку подъёма.

## Решение

- Таймер поднимается во всех точках, где условие может появиться: старт процесса при уже существующем состоянии И момент его создания (`startSupervisorRun` → `startSupervisorTimer`). Вызов делай идемпотентным (`if (tickTimer !== null) return true`) — тогда дублирующий вызов бесплатен.
- Ошибку подъёма не глотать молча и не отменять уже выполненную работу: `try/catch` + `console.error`, основной результат остаётся успешным.
- Гаси во всех терминальных точках: явный stop, авто-отзыв (все задачи терминальны), неуспешный старт, `server.close`/`error`. Перед гашением проверяй, что активных прогонов не осталось (`stopTimerIfNoActiveGrant`) — иначе убьёшь таймер соседнего прогона.
- Единственное место, где нужен self-stop изнутри интервала, — условие, которое некому заметить извне (истечение `expiresAt`): в теле тика `if (res.skipped === 'no-grant') stopSupervisorTimer()`.

## Пример

```ts
// старт прогона — вторая точка подъёма (сервер уже работает!)
try { startSupervisorTimer(cwd); }
catch (err) { console.error('[supervisor] таймер не запущен:', (err as Error).message); }
// self-stop внутри интервала — единственный путь заметить истечение срока
.then(res => { if (res.skipped === 'no-grant') stopSupervisorTimer(); })
```

Тест на инфраструктуру планировщика обязан проверять не только «тик работает», но и «таймер поднялся при появлении условия» и «снялся на stop/авто-отзыве» (`isSupervisorTimerRunning()`), с `afterEach(() => stopSupervisorTimer())` при `isolate: false`.
