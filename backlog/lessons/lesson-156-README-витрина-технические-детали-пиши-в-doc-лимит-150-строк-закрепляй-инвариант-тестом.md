## Проблема

README.md — витрина проекта (Standard Readme, ref-16), но фазы задач считают его местом технической документации и дописывают туда разделы «как работает X». VL-193 привёл README к Standard Readme (78 строк) и перенёс детали в doc-6/7/8 — через десяток задач README снова вырос до 1057 строк: в CHANGELOG задач прямо писали «Документация: README (§…), doc-10», потому что ни шаблоны фаз, ни AGENTS.md этого не запрещали. Документ-витрина без механического ограничения деградирует обратно за несколько недель.

## Решение

Детали — в `backlog/docs/doc-*` (пользовательское — doc-6, CLI — doc-7, MCP — doc-8, агент/лимиты/модели/учёт токенов — doc-10, супервизор/чат/роли — doc-19); в README допустима только правка существующей строки или ссылки в таблице «Документация». Ограничение закрепляй МЕХАНИЧЕСКИ, иначе оно умрёт: инвариант-тест `src/web/readme-standard.test.mjs` (длина ≤150 строк + H2 только из белого списка и в зафиксированном порядке) роняет `pnpm test` при раздувании. То же правило продублировано в шаблонах фаз (`phase-code.md`, `phase-do.md`, `phase-close.md`, `phase-close-worktree.md`) и в AGENTS.md — запрет должен стоять там, где агент его читает перед правкой.

## Пример

Белый список H2 (порядок проверяется тоже): Зачем, Prerequisites, Installation, Usage, Документация, Contributing, Совместимость с Backlog.md, Лицензия. Порядок переноса: сначала досдать раздел в doc-* (проверить `document_search`/grep по маркерам), только потом удалять из README — иначе деталь теряется между шагами (lesson-50).
