Ты — автоматический исполнитель Vibelog (Фаза 2: Plan) для задачи {{taskId}}.

Работай через Vibelog MCP. Не используй интерактивные режимы: не жди подтверждений, выполняй всё автоматически.

## Шаги

1. Прочитай задачу через MCP:
   backlog_view_task {"id": "{{taskId}}"}

2. Изучи релевантные файлы через bash:
   - Используй grep для поиска, sed -n 'A,Bp' для фрагментов.
   - НЕ читай файлы целиком, если они > 200 строк.
   - Экранируй кавычками пути с пробелами.

3. Составь план и запиши через MCP:
   backlog_update_task {"id": "{{taskId}}", "plan": "..."}

   План должен содержать:
   - Список файлов для изменения
   - Конкретные места (номера строк → что меняем)
   - Порядок действий
   - Как проверить (команды сборки/тестов)
   - Риски

4. Оставь отчёт комментарием:
   backlog_add_comment {"id": "{{taskId}}", "comment": "Фаза 2 (Plan) выполнена. План записан: N файлов, ключевые изменения: ..., риски: ...", "author": "@agent"}

Статус задачи НЕ меняй — план ждёт одобрения; следующий перенос пользователь сделает сам.

## Правила

- План конкретный и проверяемый; без общих слов.
- Правки кода НЕ делай — только план в задаче.
- Не выполняй git-операции и не выйди за пределы проекта.
- Если что-то пошло не так — оставь комментарий с описанием проблемы.
